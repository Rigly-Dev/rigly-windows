# Rigly for Windows

Downloads and updates for [Rigly](https://getrigly.com) on Windows, a local PHP development environment (in beta).

- **Install:** download `RiglyApp-win-Setup.exe` from the [latest release](https://github.com/Rigly-Dev/rigly-windows/releases/latest)
  and run it. It installs for your user account, without an administrator prompt. Rigly updates itself after that.
- **Not code-signed yet:** Windows may show "Windows protected your PC" the first time. Choose **More info → Run anyway**.
- **Feedback:** [report a bug, suggest a feature or ask a question](https://github.com/Rigly-Dev/rigly-windows/issues/new/choose),
  or use **Send Feedback (Beta)** in Rigly's tray menu, which fills in your versions.

Rigly for Mac: [Rigly-Dev/rigly-mac](https://github.com/Rigly-Dev/rigly-mac). Documentation: [getrigly.com/docs](https://getrigly.com/docs/).
